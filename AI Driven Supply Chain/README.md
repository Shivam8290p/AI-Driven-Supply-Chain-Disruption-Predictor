# AI-Driven Supply Chain Disruption Predictor

This project contains the frontend template for the Supply Chain Disruption Predictor.

## Included
- `templates/index.html` — HTML/CSS frontend for entering shipment details and displaying prediction results.

## Note
The uploaded source material contained the frontend HTML code, but did not include the Flask/Python backend, trained model file, dataset, or requirements file. Those files would need to be added separately before the complete application can be run from GitHub.
